Use these guides to submit PDFs, follow processing, check extracted information
and complete page-splitting decisions. Your administrator supplies the app
address, sign-in details, approved pipeline/version and expected output location.
Use the **operator** account for everyday work. Administrators can also perform
these tasks, but operators do not configure processing or change account passwords.

## Find the right guide

1. [Process your first document](quick-start.md): sign in, understand the work
   areas and follow a document from submission to results.
2. [Submit documents](submitting-documents.md): select a pipeline, prepare PDFs,
   follow upload limits and recover from an uncertain transfer.
3. [Monitor processing and find results](monitoring-and-results.md): interpret
   statuses, check split children and compare extracted with final values.
4. [Review extracted information](reviewing-extracted-data.md): find and claim
   work, correct fields/rows, save progress and complete a review.
5. [Split a PDF during review](manual-splitting.md): decide boundaries, save a
   plan and confirm split or no split.
6. [Resolve problems and request help](troubleshooting.md): investigate failures,
   distinguish retry actions and give support the right information.

## Choose your next action

| Situation | Where to go |
| --- | --- |
| New PDFs ready to submit | Upload & Process, or the incoming folder approved for that document type |
| You need to find an earlier batch | Reports, then Recent Batches and Open processing dashboard |
| A person must check values or choose page boundaries | Review Queue; check whether the item is extraction review or Manual split |
| A document cannot finish | Its failure link or Failures; compare recorded errors with current progress |
| You need saved values | The document's Extraction page; it is a results screen, not an editing screen |

Uploading, finishing review and finishing processing are separate milestones.
Saving a review draft does not complete it. Splitting a PDF can create several
documents that need separate review. Check the final processing outcome and
required files before treating the work as finished.
