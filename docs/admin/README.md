Use these guides to configure processing through the app. Programming knowledge
is not required. IT/support installs and operates the deployment, prepares
connections and folders, and handles recovery.

For initial configuration: arrange folders/connections with IT, create and
publish the review form, configure and publish its pipeline, activate it, then
test a PDF before enabling routine intake. You can also use the
[Operator guides](../operator/README.md) for everyday processing.


For a new document type, begin with extraction selection and the review form,
then assemble the pipeline. The pipeline guide includes a worked invoice
setup, and the task guide explains every supported built-in operation.
Screen instructions include the decisions behind the settings; the technical
references remain available for implementation and file-format details.

Choose the task you need:

1. [Manage pipelines and published versions](managing-pipelines.md)
2. [Configure extraction for a document type](configuring-extraction.md)
3. [Manage review forms](managing-review-forms.md)
4. [Choose and configure all available pipeline tasks](task-guide.md)
5. [Manage incoming folders](managing-watch-folders.md)
6. [Manage passwords and settings](accounts-and-settings.md)
7. [Validate settings and inspect administrative history](validation-and-audit.md)
8. [Archive pipelines and clean processing history](archiving-and-retention.md)

Before enabling routine intake, confirm the full business outcome: expected
pages and values, usable review controls, corrected final exports, accessible
PDF copies and any reference-file updates. Configuration validation alone does
not test those outcomes. Record the tested pipeline/form versions and explicitly
assign the intended published version to each watch folder.
