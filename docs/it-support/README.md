Use these procedures to operate the Windows deployment. Application admins
manage pipelines, forms and intake assignments through the app; coordinate
maintenance and verification with them. Use PowerShell from the repository root
and the repository virtual environment for Python commands.


Read in this order, or choose the task you need:

1. [Install the app and extraction providers](installation-and-provider-setup.md)
2. [Configure paths, permissions and secure access](configuration-and-access.md)
3. [Provision accounts or recover administrator access](account-recovery.md)
4. [Start, stop and restart](starting-and-stopping.md)
5. [Monitor health and logs](monitoring-and-logs.md)
6. [Back up, restore and maintain storage](backup-and-restore.md)
7. [Deploy, upgrade and roll back](deployment-and-upgrades.md)
